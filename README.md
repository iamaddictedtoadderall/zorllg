# Physics Toybox

A 2D physics sandbox in one HTML file. Open `index.html` in a browser.

- **Tools (keys 1–9):** Grab, Ball, Box, Shape, Balloon, Wall, Rope, Blast, Eraser
- **Settings:** gravity (Moon, Jupiter, flipped…), bounciness, slow motion, pause
- **Scenes:** pyramid, dominoes, Newton's cradle, ball pit

Built with [Matter.js](https://brm.io/matter-js/).
